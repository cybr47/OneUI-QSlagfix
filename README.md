# ShadeSwitch — Glass fade without bounce (experimental)

This branch preserves the **GlassUI-style horizontal page crossfade** confirmed by user testing on `v2-glass-native`, while removing the elastic element bounce and delayed spring settling.

## What stays

- Samsung's original notifications, Quick Settings, media player, clock/date, and interactive buttons.
- Full-width horizontal movement of existing Samsung pages, instead of stock Samsung ±300/250px visual transforms.
- **Unchanged fade curve:** `alpha = clamp(shown * 1.5, 0, 1)` on each page (inverse for the opposite page), including notification blur-background synchronization.
- The existing `HorizontalTransitionPanels` native view binding, Compose scene pinning and property restoration.
- Original `area-increase` header-only vertical gesture when the Vertical swipe setting is ON.
- Together mode's independent **Hide Quick QS row** toggle.

## What was deliberately removed

- `GlassMotionPhysics.java`: the FOLLOW 0.15s, SETTLE 0.34s, and TAIL 0.24s springs.
- The follow/settle velocity state, trailing-edge spring/stretch, and `scaleX/scaleY` effect.
- The additional `Choreographer.FrameCallback` loop, separate from Samsung's native transition progress.
- Temporary forced hardware-layer promotion. No extra view animations are started.

**No elastic overshoot or independent inertia is now generated by our module.**
Movement uses the exact native slide-progress fraction on each `PanelTransitionAnimator.slide` callback, while Samsung still owns gesture recognition, timeline/release, panel-state notifications and close handling.

**Important:** The alpha-vs-progress curve is unchanged, but its perceived timing may differ because the fraction no longer lags behind the finger/native animator through an additional spring.

## Performance findings motivating the change

The supplied `glass_native_trace` has 1,056 completed NotificationShade surface frames, including 110 full-jank and 14 partial-jank frames (**11.7%**). Median surface-frame span **12.23ms**, p95 **18.52ms**, max **68.62ms**.

Earlier recordings: Samsung baseline 12.4% jank (797 frames, median 8.52ms); GlassUI full replacement 5.1% (1,495 frames, median 5.85ms); release-interpolator experiment 11.3% (868 frames, median 8.32ms). The recordings have different lengths and work; these are not controlled per-swipe benchmarks. The new spring-free code has **not** yet been profiled.

## Testing/rollback

Disable the separate GlassUI LSPosed module so two animation systems don't interfere. Install this branch's signed `app-release.apk`, enable ShadeSwitch for SystemUI, restart SystemUI, and leave **Vertical swipe to switch panels OFF**. Compare both swipe directions and reversals, plus media-card visibility and clock/date elements. Ensure the panel stops with the native swipe/release and the fade still matches preferences.

The log should show `Glass fade-native horizontal hooks installed` and `Glass fade frame applied` when horizontal transitions occur.

The original `v2` and `v2-glass-native` branches are unchanged. Uninstall or replace with the earlier signed `v2-glass-native` build to return to spring motion; either build shares the package ID/versionCode/signing key.
